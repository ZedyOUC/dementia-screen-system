# dementia‑screen‑system
面向医院的阿尔茨海默病前期认知筛查评估系统

## 📖 项目简介
解决纸质认知筛查量表手工计分容易出错、病历难以归档统计的痛点。
整套系统分为两部分：
1. 微信小程序端：医护人员录入患者信息，完成认知量表答题筛查
2. Web管理后台：电脑端查看筛查记录、自动生成评估报告、导出数据
后端基于微信云开发（云函数 / 云数据库 / 云存储）实现，零服务器成本。

## 🛠️ 技术栈
- 后端底座：微信云开发（Node.js云函数）
- 小程序前端：微信原生小程序
- Web后台：Vue3 + Element‑Plus
- 协作工具：Git + GitHub

## 👥 小组分工（7个独立任务包）
1. task1‑score‑engine：数据表设计、认知评分计算引擎
2. task2‑cloud‑base：云开发底层基础服务（鉴权、数据库封装、文件上传）
3. task3‑business‑api：业务云函数接口（患者管理、测评记录）
4. task4‑web‑admin：Web电脑管理后台开发
5. task5‑wechat‑mini：微信小程序前端页面开发
6. task6‑ui‑design：UI原型图、量表素材、设计资源
7. task7‑test‑doc：功能测试用例、项目文档、结题报告

## 不要在作业中声称已经完成的事项

- 云函数正式业务 API 已上线；
- PostgreSQL 已被本地后端自动连接；
- 微信小程序真实身份登录已经完成；
- 云存储上传/下载已经完成；
- 已经配置生产级监控、告警或多实例容灾。

除非控制台中确实出现了对应成功结果，否则这些只能写成“待部署”或“未配置”。

## 日常运维最小方案

每次演示前：

1. 检查云函数最近一次调用是否成功；
2. 检查 PostgreSQL 中 7 张表仍存在；
3. 检查本地后端 `GET /api/v1/health`；
4. 检查文件上传和下载各一次；
5. 将异常请求的 `requestId` 记录下来，方便和日志对应。
